# Ludotheca

Проверяемая энциклопедия игр и игровых механик, описанных в литературе, мифологии и фольклоре.

## Принципы

- Только факты из конкретных текстов и редакций. Никакой реконструкции или вымышленных правил.
- Одно произведение за один проход; регистрировать даже произведения без подходящих игр.
- Название необязательно, если источник описывает конкретное игровое действие, правило, цель или механику. Редакционное название обязательно помечать.
- Одного названия, факта игры или количества участников недостаточно.
- Общеизвестные традиционные игры включать только при доказанном отличии правил или необычной механике; сравнение подтверждать источником.
- Не смешивать варианты одной игры: одна общая карточка, отдельные свидетельства для каждого произведения.
- `added_at` неизменен после первого добавления, `updated_at` меняется при содержательной правке.
- Нет прототипов, идей адаптации и оценок цифровой реализации.

## Структура

- `data/games/*.yaml` — единая карточка игры и отдельные свидетельства по произведениям.
- `data/games/index.json` — список путей карточек для сайта.
- `data/processed-works.yaml` — реестр исследованных произведений, включая нулевые результаты.
- `schema/game.schema.json` — проверяемая схема карточки.
- `schema/processed-works.schema.json` — схема реестра.
- `index.html`, `app.js`, `styles.css` — статический каталог.

## Добавление

1. Выбрать ещё не обработанное произведение и конкретную доступную редакцию.
2. Прочитать первоисточник, извлечь все игры, отвечающие критериям.
3. Проверить существующие `id` игр и добавить новое свидетельство либо новую карточку.
4. Указать место в тексте и ссылку, отделяя действия персонажей от универсальных правил.
5. Обновить реестр и даты; открыть один Pull Request.

Сайт использует js-yaml через CDN для чтения YAML; при отсутствии сети загрузка данных может быть недоступна.
